# 민지로그 | MINJI LOG — 공식 링크 페이지

인스타그램 · 스레드 · 유튜브 프로필에 연결하는 민지로그 쇼핑 링크 페이지입니다.

- `index.html` — 페이지 본체 (모바일 우선, 단일 파일)
- `thumbs/p001.jpg` ~ `thumbs/p008.jpg` — 상품 카드 왼쪽 썸네일 (320×320 JPG)
- `profile.png` — 프로필 이미지
- `apple-touch-icon.png` — 홈 화면 추가용 아이콘

상품 링크를 바꾸려면 `index.html` **맨 위**(`<head>` 안)의 `PICKLOG_LINKS` 값을
쿠팡 파트너스 단축 주소로 바꾸면 됩니다. 키(`P001`·`P002`·`P003`)는 내부 관리용
상품번호로, 화면에는 표시되지 않습니다. 외부에 이미 배포한 `?q=P003` 같은 주소는
계속 해당 상품만 보여 줍니다.

새 상품을 추가할 때는 카드 하나를 복사해 `data-num`(상품번호), `data-cat`(카테고리),
`data-keywords`(검색어)와 `data-link`(링크 키)를 맞추고, 같은 이름의 썸네일을
`thumbs/`에 넣어 주세요. 검색과 탭은 자동으로 붙습니다.
